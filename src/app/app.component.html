01 · Fundamento financiero

Caso de estudio: planificación de recursos

Una organización distribuye recursos entre cuatro áreas esenciales. Cada área posee una prioridad financiera y un costo marginal de desvío presupuestario. Existe interdependencia: un cambio en una unidad repercute en las demás.

La propuesta minimiza una función cuadrática de costos/desajustes. Su condición de primer orden genera el sistema Ax = b; la matriz A representa sensibilidades e interdependencias, mientras b cuantifica prioridades de asignación.

Origen de los datos: valores sintéticos diseñados para una demostración académica, no presupuestos observados de una entidad real. Se expresan asignaciones x en miles de bolivianos (miles de Bs) y coeficientes financieros normalizados.

02 · Formulación matemática

Sistema lineal y condición de optimalidad

Función objetivo

J(x) = ½ xᵀAx − bᵀx
∇J(x) = Ax − b = 0
∇²J(x) = A ≻ 0

Cuando A es simétrica definida positiva, J es estrictamente convexa y el sistema Ax = b tiene una solución óptima única.

Criterios verificables

A = Aᵀ
Δ₁ > 0, Δ₂ > 0, …, Δₙ > 0
κ₂(A) = λmáx(A) / λmín(A)

Se comprueba simetría directamente y definición positiva mediante Cholesky / criterio de Sylvester. El número de condición se estima con autovalores de matrices simétricas.

07 · Análisis crítico y referencias

Conclusiones matemáticas, financieras y de software

Convergencia

La SPD de A garantiza solución única; GCP transforma el sistema mediante un precondicionador SPD. La rapidez depende del espectro y de la selección de M, no solo de la tolerancia.

Interpretación financiera

Los cambios en b y A reflejan prioridades y sensibilidades de costo. La comparación permite distinguir perturbaciones de demanda de un problema de mal escalamiento.

Calidad del software

La entrada editable y la validación preventiva evitan resolver matrices incompatibles. La solución directa, el residual verdadero y QA permiten comprobar resultados de forma reproducible.

Una función objetivo de desajuste presupuestario J(x)=½xᵀAx−bᵀx permite combinar penalización del desvío por unidad (diagonal de A) y sensibilidad entre unidades (coeficientes fuera de diagonal). b expresa prioridades financieras ponderadas. Al resolver ∇J(x)=0 se obtiene Ax=b. Para los casos predeterminados, b se construye a partir de asignaciones objetivo didácticas; el usuario puede reemplazarlo. No se modela un presupuesto total fijo.

aᵢᵢ : sensibilidad/cuadrática marginal
aᵢⱼ : interdependencia entre dos unidades
bᵢ : prioridad marginal ponderada
xᵢ : miles de bolivianos asignados

Según el algoritmo de Suñagua (2020), se inicia en x₀ y se calcula r₀ = b−Ax₀. Para cada iteración se resuelve M zₖ = rₖ, se actualiza la dirección conjugada pₖ y se determina αₖ. El procedimiento implementado es equivalente a la formulación clásica PCG con β de Fletcher–Reeves precondicionado.

r₀ = b − Ax₀ ; z₀ = M⁻¹r₀ ; p₀ = z₀
αₖ = (rₖᵀzₖ) / (pₖᵀApₖ)
xₖ₊₁ = xₖ + αₖ pₖ
rₖ₊₁ = rₖ − αₖ A pₖ
zₖ₊₁ = M⁻¹ rₖ₊₁
βₖ = (rₖ₊₁ᵀ zₖ₊₁) / (rₖᵀ zₖ)
pₖ₊₁ = zₖ₊₁ + βₖ pₖ

Criterio: ||b−Axₖ||₂/||b||₂ < 10⁻⁶ por defecto. Se usa el residuo verdadero para verificar la parada. GC simple corresponde a M=I.

Jacobi establece M=diag(A) y resulta conveniente cuando la principal dificultad proviene de escalas diagonales muy diferentes. SSOR forma una aproximación SPD utilizando la diagonal y las componentes estrictamente inferiores/superiores; puede ser útil cuando hay acoplamiento más fuerte. Elegir M=I reproduce GC.

M_J = diag(A)
M_SSOR = (D+ωL)D⁻¹(D+ωU) / [ω(2−ω)]
0 < ω < 2 ; A = D + L + U

Se muestran dos indicadores distintos: la condición κ₂(M⁻¹A) mediante normas 2 inducidas y el cociente λmáx/λmín de la matriz simétrica Lₘ⁻¹ A Lₘ⁻ᵀ, semejante a M⁻¹A y pertinente para analizar PCG.
